Error handling¶

SDK validation and lookup errors are separate from Oracle driver errors. Catch a specific SDK exception when the application can recover from it. Database and provider failures surfaced by PL/SQL can raise oracledb.DatabaseError; inspect the driver error code when deciding what the application should do. Avoid retrying authorization or configuration failures without correcting their cause.

import oracledb
import select_ai

# Assumes an open connection. Missing profiles are not created here.
try:
    profile = select_ai.Profile.fetch("APP_PROFILE")
    answer = profile.chat("Explain retrieval augmented generation.")
except select_ai.ProfileNotFoundError:
    print("Create APP_PROFILE or choose an existing profile.")
except select_ai.DatabaseNotConnectedError:
    print("Establish a connection before using the profile.")
except oracledb.DatabaseError as exc:
    error, = exc.args
    print(f"Database operation failed (code {error.code}).")
    raise

Do not expose raw database errors or connection credentials in public HTTP responses. For web applications, translate expected failures into your application’s error response and close pools in the application shutdown hook.
